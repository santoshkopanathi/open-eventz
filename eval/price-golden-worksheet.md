# Golden set - labelling worksheet

**Do not look at what the app currently says.** Label from the source text only.

## The rules - read BEFORE you start, and do not change them mid-way

Two labels per event. Do KID first - it is quicker and it frames the price question.

### KID - is this genuinely an event for children?

Write **yes** or **no**.

- **yes** - children are a real intended audience. Family events count as yes.
- **no** - adults only (21+, wine tastings), or not an event for attending at all
  (vendor applications, board meetings, dog swims).

**Things that are not events at all** - vendor applications, board meetings, "registration opens
today" notices - are **no**. They are announcements aimed at businesses or the council, not
something a family attends. Add a NOTE so it is clear it was that kind of no, not an adult-only no.

Do not overthink borderline cases - ask whether a parent would reasonably bring a child.

### PRICE - what does it cost a parent to attend?

Write exactly one of three values:

- **free** - attending costs a parent nothing. A donation being *welcome* is still free.
- **paid** - it costs money for at least some families. "Free to members, $7 otherwise" is **paid**.
- **unknown** - you genuinely cannot tell. This is a legitimate answer, not a failure to decide.
  A set with no unknowns in it is a set someone guessed on.

**60-second rule.** If you cannot decide a PRICE within a minute, write unknown and move on.
KID should take five seconds; if it genuinely does not, write no and add a NOTE.

**ALSO-OK line.** If unknown is right but another answer would not be *wrong*, put it there
(e.g. ALSO-OK: free). Leave blank otherwise. This is how ambiguous cases get scored fairly.

**Label from the description first, THEN open the link.**

This order matters. The model only ever sees the title and description - it never sees the
page. So decide your answer from the text above, then open the link to check.

If the link CHANGES your answer, write the final (true) answer on the PRICE line and add
a NOTE saying the price was only on the page. That one word separates two different
problems: the model misreading text it was given, versus the scraper never capturing the
price at all. Those need completely different fixes, and without the note they look identical.

**NOTE is free text.** Leave it blank most of the time. Use it for: where you found the price,
why a case was hard, an empty description, or a rule you invented part-way through. Recording
an invented rule means it gets applied to the earlier items at scoring time instead of you
going back to redo them.

**Never revise an earlier label.** If your standard shifts, write the new rule in a NOTE and
keep going forwards. Silent drift in your own judgement is the one thing that ruins a golden set.

**You can stop anywhere.** The order is randomised, so a partial pass is still a valid sample.
Items 1-38 are every Play Frisco event that exists (a census, not a sample).
Items 39-68 are a random 30 of Kaleidoscope Park.
